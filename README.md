# 企业经营分析决策平台

面向企业高层管理的经营分析决策平台。覆盖经营指标看板、财务多维分析、销售漏斗洞察、客户画像构建、供应链效率监控、人力效能评估、经营预测模型、异常预警与决策建议推送的完整企业分析链路。

这是一个前后端分离的管理平台：前端 Vue 3 + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/              统一请求封装
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/          每个业务模块一组接口
│   ├── app/services/         业务规则与状态流转
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8000/api/health`

### 前端

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8000`。

## 约定

- 每个模块的前端页面在 `frontend/src/views/<模块>/index.vue`，后端接口在
  `backend/app/routers/<模块>.py`，业务规则在 `backend/app/services/<模块>.py`。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。

## 财务预算核算

财务多维分析下新增预算核算能力（前端页面 `/finance/budget`，接口前缀
`/api/finance/budget`），把预算条目、费用凭证与冲销记录核算成预算执行差异数据集，
供经营分析报告端生成科目对账附件（`POST /api/report/{id}/budget-attachment`）。

核算口径：

- 金额内部一律换算为**最小货币单位整数**（`app/services/budget_money.py`），分摊采用
  最大余数法，尾差逐行留痕，分摊合计与原费用严格闭合；不同币种分组隔离、绝不直接相加。
- 同一凭证号的多行即多个分摊项，可涉及不同科目与部门；冲销按原凭证实际占比（或显式
  冲销项比例）拆分，支持部分冲销、同号多笔冲销与跨期冲销；只有已完成且同周期的冲销
  才计入实际金额，未完成冲销只登记不抵减。
- 预算周期（年度/季度/月度）与费用发生日期共同决定计入范围；预算按「周期+科目+部门+
  币种」精确关联，未单列预算按零预算处理。
- 导入按内容指纹与批次号双重幂等，重复导入只记一次；缺少原凭证、比例合计不符、金额
  无效、冲销超额等行全部进入异常清单并附原因。
- 每次核算生成不可变的**核算依据**快照（`/api/finance/budget/bases`）；恢复核算在数据
  未变时复用依据、不重复分摊，更正生成新版本，旧报告始终绑定旧依据对应的预算与凭证集合。
- 端到端校验脚本：`backend/tests/test_budget_accounting.py`（51 项断言，覆盖三份拆分
  尾差、跨期部分冲销、同号重复凭证、零预算科目与附件金额闭合）。
